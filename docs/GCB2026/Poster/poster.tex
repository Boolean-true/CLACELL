\headerbox{Motivation}{name=motivation, column=0, span=2}{
\begin{itemize}
\item \highlight{Background:} Single-cell RNA sequencing (scRNA-seq) reveals cellular heterogeneity, but assigning cell types remains a massive analytical bottleneck.
\item \highlight{Problem:} Manual marker-based annotation is highly subjective and scale-limited and existing automated classifiers often suffer from high performance variance, sensitivity to gene dropout, and overfitting.
\item \highlight{Our approach:} We propose CLACELL, an open-source Python framework for robust and deterministic cell type classification of single-cell data.% and spatial transcriptomics data.
\end{itemize}
}

\headerbox{The CLACELL Package}{name=package, column=0, span=2, below=results_fine_grained}{
End-to-end Python solution for robust scRNA-seq classification:
\begin{itemize}
\item \highlight{MarkerAnnotator:} Native Python reimplementation of the \textit{scumi} R algorithm.
\item \highlight{preprocess\_data:} Built-in pipeline (normalization, log-transform, feature selection).
\item \highlight{CellClassifier:} Custom Ensemble with built-in methods for hyperparameter tuning, training, evaluation, and prediction.
\item \highlight{ConditionalCellClassifier:} Conditional Autoencoder with built-in methods for hyperparameter tuning, training, evaluation, and prediction.
\end{itemize}
}

\headerbox{Future work}{name=conclusion, column=2, span=2, below=cae_architecture, above=bottom}{
\begin{itemize}
\item \highlight{Optimization of CLACELL:} Stacking and a combination of Custom Ensemble and Conditional Autoencoder.
\item \highlight{Hierarchical Classification:} Implement a two-level approach for improved performance.
\item \highlight{Spatial Data Evaluation:} Assess CLACELL's performance with low gene counts.
\end{itemize}
